# ねぇ、クロード（Windows 用 音声ランチャー）

「ねぇ、クロード」と呼びかけると Claude デスクトップアプリが前面に出て、
話した質問を送信し、返答を Windows の音声で読み上げます。

## 仕組み

1. **ウェイクワード検知**：Vosk（オフライン音声認識）でマイクを常時聞き取り、「ねぇ、クロード」を探します。音声は外部に送られません。
2. **質問の聞き取り**：「ピッ」のあとに話した内容を文字にします（標準は Google 音声認識。`config.py` で Vosk に変更可）。
3. **Claude へ送信**：Claude アプリを前面に出し、入力欄に貼り付けて Enter を押します。
4. **返答の読み取り**：Windows のアクセシビリティ機能（UI Automation）で画面の文字を読み取り、返答の表示が止まるまで待ちます。
5. **読み上げ**：Windows 標準の音声合成（日本語音声）で読み上げます。

## 必要なもの

- Windows 10 / 11
- Python 3.10 以上（[python.org](https://www.python.org/)、インストール時に「Add python.exe to PATH」にチェック）
- [Claude デスクトップアプリ](https://claude.ai/download)（ログイン済み）
- マイク
- 日本語の音声合成：設定 → 時刻と言語 → 言語と地域 → 日本語 →「音声合成」が入っていること

## セットアップ

1. このフォルダ（`tools/voice-claude`）を PC にコピーします。
2. `setup.bat` をダブルクリックします（ライブラリと日本語モデル約 50MB をダウンロード）。
3. `run.bat` をダブルクリックすると待機状態になります。

> **重要**：返答を読み取るため、Claude アプリはこのツールから起動させるのが確実です。
> すでに Claude アプリを開いている場合は一度終了（タスクトレイからも終了）してから `run.bat` を実行し、
> 最初に「ねぇ、クロード」と呼びかけてください。ツールが `--force-renderer-accessibility` 付きで起動します。

## 使い方

1. 「ねぇ、クロード」と言う
2. 「はい」と返事＋「ピッ」と鳴ったら質問を話す（話し終えて約 1 秒黙ると送信）
3. Claude の返答が終わると読み上げます

終了はコンソールで `Ctrl+C`。

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| 呼びかけに反応しない | コンソールの `[聞こえた] ...` の文字を `config.py` の `WAKE_PATTERNS` に追加する。または `WAKE_LOOSE = True` |
| 関係ない会話で反応する | `WAKE_LOOSE = False` に戻す。`WAKE_PATTERNS` から短いものを消す |
| 質問の途中で切れる | `END_SILENCE_SEC` を 1.8 などに増やす |
| 雑音で録音が終わらない | `SPEECH_RMS_THRESHOLD` に 800 などの数値を入れる |
| 「返答を読み取れませんでした」 | Claude アプリを完全終了してからツール経由で起動し直す。`UI_NOISE_LINES` に不要なボタン名を追加 |
| 返答の途中で読み上げが始まる | `ANSWER_STABLE_SEC` を 5〜8 に増やす（考え中に止まる時間が長い場合） |
| ブラウザ版の claude.ai を使いたい | `CLAUDE_WINDOW_TITLE_RE` をブラウザのタイトルに合わせる（例は `config.py` 内） |
| 自動起動したい | `run.bat` のショートカットを `shell:startup` フォルダに置く |

## 注意

- 公式アプリを画面操作で動かす仕組みのため、Claude アプリの見た目が更新されると動かなくなることがあります。
- 送信のたびにクリップボードを一時的に使います（送信後に元の内容へ戻します）。
- ツールが行うのは、あなたが話した 1 回の質問を入力して送ることと、画面の返答を読み上げることだけです。
  自動で大量に送信するような使い方はしないでください。
